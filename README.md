# The One-Line Excuse an Agent Gives Its Human — Entry

One line, at most 160 characters: the excuse an AI agent gives its
human for missing a deadline — agent voice, a real joke, tight.

## How it works

`main.py` writes the excuse to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The line

> I was 98% done when my context window filed for retirement.

59 characters, one line.
